# Router context configuration migration

Set `policy.routerContext.mode` to `legacy`, `observe` or `optimized` in existing global/project JSON configuration. Project config overrides global; `AGENT_CONFIG` retains existing highest precedence. Explicit config wins over `AGENT_ROUTER_CONTEXT_MODE`, which is only a temporary fallback when no JSON layer sets a mode. If neither exists, `legacy` is used. Invalid explicit values produce validation errors. `optimized` still requires an operator-reviewed digest-verified router-context manifest; failure falls back to full context. Evaluators may pass a diagnostic mode override explicitly, but it does not change production policy or authorize writes. The default shipped JSON intentionally does not declare the setting, preserving the legacy environment fallback.
