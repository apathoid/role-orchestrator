# Roadmap — будущая постоянная точка входа

**Статус на 10 ноября 2026: C12.0 запланирован, миграция ещё не выполнена.** Этот каталог закреплён за активным планом, статусом и остающимися обязательствами **после** C12.0. Сейчас источники истины находятся в `development/START_HERE.md`, `development/plan/IMPLEMENTATION_PLAN.md`, `development/plan/clusters/C12_ACCEPTANCE_DELIVERY.md`, `development/STATUS.md` и `development/quality/ACCEPTANCE_MATRIX.md`. При C12.0 сюда переносятся действующий план, невыполненные C12.1–C12.9, зависимости и `STATUS.md` (следующая задача, выполненные проверки, commit/CI/evidence, blockers и native UNVERIFIED). Даётся ссылка на **единственную** матрицу R01–R33/A01–A54 и действующие тесты. Документация продукта остаётся в предметных `docs/`, причины решений — в `docs/DECISIONS.md`/ADR, история существенных изменений — в `CHANGELOG.md`, исторические подробности — в Git.

После миграции корневые `AGENTS.md` и `README.md` должны вести к roadmap. Код/CI/документация обновляются согласованно; до C12.0 весь существующий harness остаётся действующим.
