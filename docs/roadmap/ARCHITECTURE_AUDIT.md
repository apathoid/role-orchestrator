# C12.7 — Содержательный аудит архитектурных инвариантов

Проверка по исходникам на commit `479f6ea`, ветка `greenfield/model-first-core`, 2026-11-10. Это **статический кодовый audit (SUPPORTED)**, не end-to-end тест живого provider и не формальное доказательство отсутствия всех возможных дефектов. Regression CI даёт отдельный уровень OBSERVED. Критерии: [AGENTS.md](../../AGENTS.md), [ARCHITECTURE](../ARCHITECTURE.md), [DECISIONS D01–D16](../DECISIONS.md).

| Ограничение | Проверенные кодовые пути и факты | Оценка/границы |
|---|---|---|
| Нет Host-fixed workflow | `src/application/orchestrator.js` обрабатывает model Decision с actions/wait/continue; `src/application/action-round.js` координирует dispatch; `src/core/action-graph.js` проверяет зависимости, но не навязывает Explorer/Planner/Reviewer | SUPPORTED на просмотренных переходах; модель всё ещё может сама предпочесть фиксированную стратегию |
| Нет provider-name branching в core | `src/core/operation.js`, `snapshot.js`, `ports.js` описывают providerId как данные; конкретные Codex CLI и ACP настройки изолированы в `src/adapters/cli/codex-provider.js` и `src/adapters/acp/provider.js`. `scripts/check-boundaries.mjs` разбирает import AST | CI проверяет запрет core imports извне; статический просмотр не гарантирует portability всех внешних исполнителей |
| Не требуется Git для runtime | `src/main/cli.js` использует cwd как пользовательский workspace; `src/hosts/acp.js` принимает/сохраняет session; `tests/acceptance/delivery.test.js` и `scripts/check-nix-install.sh` запускают non-Git smoke | OBSERVED в CI non-Git tests; запуск *конкретной модели* из non-Git пока UNVERIFIED |
| Нет source fingerprint/forced reconciliation | `src/hosts/acp.js` вычисляет hash **request payload** для обнаружения reuse `requestId`, не hash Git HEAD/файлов; `src/application/orchestrator.js` сохраняет historical evidence, `tests/integration/mutable-context.test.js` проверяет model-selective reread; `tests/acceptance/mutable-workspace.test.js` изменяет реальный branch/index | Request dedupe не является запретом mutable source; native provider handling отдельно |
| Нет Host isolation/защищённого filesystem runtime | `src/adapters/configuration/project-file.js` читает обычные пользовательские preferences; `src/adapters/state/local-store.js` использует file I/O и lock **для собственного состояния**, не исходного workspace; чтение/изменение проекта исполняет provider | Host не обещает non-writable cwd или защиту от effectful native tools |
| Нет второго scheduler или quality-vote | Семантическое принятие решения остаётся в model Decision, техническая очередь/бюджет — `src/application/orchestrator.js`; `src/core/operation.js` хранит единственное operation состояние. Diagnostics sink (`src/adapters/state/ndjson-diagnostics.js`) не заменяет durable state | SUPPORTED по структурным путям. Циклы модели не запрещаются новым Host gate |
| Один durable ledger и unknown effects | `src/core/operation.js` различает `not_sent/sent/unknown`, `none/possible/unknown`; `src/core/snapshot.js` кодирует контракт; `src/adapters/state/local-store.js` обеспечивает single-writer/CAS. `tests/integration/durable-dispatch.test.js` и `tests/integration/reasoning-recovery.test.js` проверяют crash/retry | OBSERVED synthetic/subprocess CI; настоящие частичные provider effects отдельно UNVERIFIED |
| Граница permissions | `src/application/configuration/authority.js` и `permissions.js` передают trusted grant/provider decisions; `src/adapters/acp/provider.js` и `src/adapters/cli/codex-provider.js` не переносят native access control в core | Native tool behavior нельзя вывести из Host grant; real allow/deny C12.3/4 UNVERIFIED |

**Результат:** в просмотренных путях нет воспроизведённого отклонения, требующего изменения продуктового кода на C12.7. Это **не** заключение о полноте всей нативной интеграции и не подмена C12.3/4. Потенциальный риск остаётся у разных реальных провайдеров (tool permissions, late outcomes, unknown effects) и подтверждается только native evidence с версиями и трассой.

Аудит не создаёт новую роль/механизм runtime, не расширяет security scope и не вводит обязательную систему reconciliation. По последнему CI и outstanding см. [STATUS](STATUS.md).
