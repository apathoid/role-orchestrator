# C07.6 — общий контракт ProviderPort

`providerContract` запускает одни и те же утверждения для управляемого порта в памяти и для производственного адаптера Codex CLI с контролируемым дочерним процессом. Адаптеры фикстур предоставляют только порт, профиль, контекст запуска и синхронизацию момента старта и продолжения. При отмене готовность процесса подтверждается после записи наблюдения в stdout. Это позволяет отличить отмену активного вызова от отмены до запуска.

Проверяется порядок наблюдений перед терминальным результатом, корреляция attemptId и возвращённых ссылок, сохранение наблюдения при сбое, адресная отмена в двух параллельных сессиях, отмена по AbortSignal и завершение при закрытии. Новый вызов проверяется через свежую сессию порта. Тесты допускают адаптеры без нативного продолжения. Отсутствующие токены остаются `null`; сообщённый ноль сохраняется отдельно от неизвестного значения.

OBSERVED на Linux, Node 24.22.1. Оба варианта прошли по пять сценариев. GitHub Actions запускает `test:contracts` отдельно от интеграционных тестов. Фикстуры находятся в `development/`. Проверка установки без этого каталога подтверждает независимость поставляемого пакета.

Нативный вызов модели остаётся UNVERIFIED. Проверка долговременного состояния и восстановления с реальным дочерним процессом относится к C07.7.
