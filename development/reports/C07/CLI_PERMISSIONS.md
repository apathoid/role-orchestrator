# C07.5 — полномочия и возможности Codex CLI

Оператор выбирает профиль через доверенный `nativeSettings.profile`. Адаптер передаёт его как `--profile=<name>` во всех вызовах. Имена ролей, пользовательский текст и модельные решения не участвуют в выборе нативных флагов. Допуск к запуску профиля остаётся за программным grant, внутреннее применение правил — за Codex.

В `exec` версии 0.165.0 стандартный headless-путь использует `AskForApproval::Never`. Исходники отдельно обрабатывают явно настроенный автоматический reviewer. Внутренние запросы подтверждения команд и файловых изменений обрабатывает `exec`; MCP elicitation отменяется внутри него. У CLI-адаптера отсутствует канал ответа на такие запросы через брокер оркестратора. Нативный профиль передаётся без подмены правил на стороне адаптера.

Адаптер публикует `configured` capabilities. Требование `permissions.interactive` или `tools.bridge` отклоняется до запуска. В результате сохраняются ключ возможности, статус и доступное объяснение. Отчёты о кодах команд дают частичную видимость. Отсутствие необязательной возможности само по себе не мешает вызову. Структурированный `command_execution.status=declined` сохраняется с provenance провайдера, а `PERMISSION_DENIED` ссылается на это наблюдение. Общий сбой инструмента или строки сообщения не создают такой вывод.

Источники — [Codex CLI в неинтерактивном режиме](https://developers.openai.com/codex/noninteractive), [обработка запросов в exec 0.165.0](https://github.com/openai/codex/blob/rust-v0.165.0/codex-rs/exec/src/lib.rs) и [перевод статусов в JSONL](https://github.com/openai/codex/blob/rust-v0.165.0/codex-rs/exec/src/event_processor_with_jsonl_output.rs).

## Проверка

- OBSERVED. Codex CLI 0.165.0 выдал справку `exec` с поддержкой `--profile`. В контролируемом дочернем процессе Controller и Reviewer получили одинаковые аргументы с заданным профилем. Брокер оркестратора не получал интерактивных запросов.
- OBSERVED. Обязательный канал approval отсутствует, Worker не стартует, а Controller получает объяснение и может сослаться на него. Проверен round-trip snapshot с этим наблюдением.
- OBSERVED. Синтетический дочерний процесс вернул как успешный результат команды при заранее настроенном разрешении, так и отказ. У отказа сохранён отдельный provenance, отсутствует код завершения инструмента и ход остаётся завершённым для модели.
- Применение реальных нативных правил, диалог с моделью и интеграция на других платформах остаются UNVERIFIED.
