# C07.4 — Controller и Worker через Codex CLI

`createCodexProvider` экспортируется программным API и создаёт `ProviderPort` из доверенного конфига. Каждая локальная сессия привязана к выбранному профилю и одному вызову. Она использует контракты запуска, процесса и фрейминга C07.1–C07.3. Отмена адресуется по сессии и attemptId. Закрытие ждёт закрытия принадлежащего сессии процесса.

Адаптер передаёт задачу, инструкции, ограничения и доступный контекст в stdin. Controller получает описание Decision v1 и возвращает один JSON-документ. Последнее `item.completed` с `agent_message` читается как ответ при подтверждённом `turn.completed` и успешном транспортном завершении. Некорректный JSON остаётся текстом, а форма полученного объекта проверяется обычным decoder оркестратора. Ошибка возвращается в существующий ход исправления. Ответ Worker остаётся текстом, включая JSON, если задача запросила структурированный текст.

Модельное сообщение, заявленный провайдером `command_execution.exit_code` и наблюдённый OS-код завершения CLI сохраняются с разным происхождением. Доступные `input_tokens` и `output_tokens` берутся из `turn.completed`. Неизвестный расход остаётся `null`. Запуск процесса оставляет внешний эффект неизвестным. При сбое транспорта ограниченный вывод и модельные сообщения сохраняются как наблюдения. Decision из такого хода не применяется.

Источники — [JSONL в Codex CLI](https://developers.openai.com/codex/noninteractive#make-output-machine-readable), [события версии 0.165.0](https://github.com/openai/codex/blob/rust-v0.165.0/codex-rs/exec/src/exec_events.rs) и [процессор JSONL этой версии](https://github.com/openai/codex/blob/rust-v0.165.0/codex-rs/exec/src/event_processor_with_jsonl_output.rs).

## Проверка

- OBSERVED на Linux, Node 24.22.1. Coordinator выполнил Controller → Worker → Controller через тестовый дочерний процесс. Код CLI 0, отдельно сообщённый код инструмента 9 и модельный отчёт о неудачной проверке привели к модельному частичному итогу с привязкой к наблюдению инструмента.
- OBSERVED. Worker сохранил структурированный текст дословно. JSON с обрамлением и Decision неправильной версии заняли по одному ходу общего бюджета и привели к исправлению с точным путём поля. До корректного сообщения ни одно решение не принято.
- OBSERVED. Ненулевой выход после `turn.completed`, `turn.failed` при exit 0, незавершённый кадр и повреждённое последнее сообщение сохранили доступный вывод и не запустили действий из Decision.
- Нативный модельный вызов Codex CLI остаётся UNVERIFIED. Поддержка и ограничения нативных разрешений описываются в C07.5.
