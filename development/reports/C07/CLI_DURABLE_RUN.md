# C07.7 — сквозная проверка CLI и долговременного состояния

Интеграционные тесты используют программный сервис, производственный CLI-адаптер, локальное хранилище и управляемый дочерний процесс Node.js с протоколом JSONL. Процесс отвечает и выполняет тестовые действия в отдельном обычном каталоге без Git. Фикстуры и их временные данные принадлежат development harness.

- OBSERVED. После старта Controller прочитал исходное содержимое файла. Тест изменил этот файл и создал другой во время вызова. Тот же процесс прочитал обновлённое состояние и вернул итог. Локальное хранилище сохранило наблюдения и итог. После открытия хранилища новым экземпляром повторная доставка запроса вернула сохранённый результат. Журнал дочерних процессов подтвердил один запуск.
- OBSERVED. CLI Worker записал отдельный внешний эффект и завершился. Тест завершил процесс оркестратора через SIGKILL перед записью исхода Worker. Новый экземпляр прочитал сохранённый dispatch без исхода. Повторная доставка запроса не запустила процессы. Явный resume запустил новый Controller, который получил неопределённость предыдущей попытки и прочитал изменившийся файл. Журнал вызовов и файл эффекта подтвердили отсутствие повторного запуска Worker.
- OBSERVED. После записи первого сообщения активный CLI-процесс отменён через API оркестратора. Исход, поздние наблюдения и SIGKILL процесса сохранились под исходной попыткой. ОС подтвердила отсутствие дочернего PID. Повторная доставка после открытия хранилища вернула ту же отменённую операцию.

Проверка crash ограничена границей после завершения CLI Worker и до commit. Она подтверждает восстановление журнала и защиту от повторного исполнения. Судьба активной группы при SIGKILL самого оркестратора остаётся UNVERIFIED. Нативный модельный вызов Codex относится к C07.8.
