# C07.8 — нативная проверка Codex CLI

OBSERVED на Linux, Node.js 24.22.1. Установлен Codex CLI 0.165.0. `codex login status` сообщил о входе через ChatGPT. `CODEX_API_KEY` и `OPENAI_API_KEY` отсутствовали.

В пустом каталоге без Git выполнен `codex exec --json --ephemeral --ignore-user-config --sandbox read-only --skip-git-repo-check -`. Через stdin передан короткий запрос вернуть слово `pong` без инструментов. Использовалась модель по умолчанию CLI. Первое ожидание ограничено 25 секундами. Диагностический запуск через владельца процесса C07.2 подтвердил `401 Unauthorized` от `chatgpt.com`, отсутствие `turn.completed` и завершение группы по дедлайну 18 секунд. В отчёте сохранены только технические признаки без учётных данных.

**Native CLI acceptance — UNVERIFIED.** Уточнение и продолжение, нативные инструменты, отказ и отмена активного модельного хода не проверены. Срабатывание локального дедлайна при ошибке доступа подтверждает только завершение процесса. Локальные доказательства A18 и A20 с контролируемым процессом остаются действительными. A38 требует отдельных нативных прогонов.

Дальнейшая реализация C08 может использовать установленный SDK и управляемые протокольные тесты независимо от доступа к модели.
