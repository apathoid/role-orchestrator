# C09 — приёмка расширений

| Критерий | Локальная проверка |
|---|---|
| A31 | Конфигурируемый плагин проходит общий ProviderPort suite и обычное делегирование Controller. Дубликат id, несовместимый major и невалидная фабрика дают отдельные причины. Неуспешная фабрика освобождает уже зарегистрированные ресурсы. Disable и uninstall сохраняют исторический finding и отклоняют только новый вызов недоступного профиля. |
| A32 | В каталоге доступны метаданные. При выборе skill передаётся буквальный текст нужной версии либо явная отметка о недоступности или усечении. Содержимое skill не предоставляет доступ к профилю. |
| A39 | CLI и ACP проверены через управляемые дочерние процессы и настоящий локальный MCP endpoint. Проверены отказы схемы и разрешения, корреляция результата, отмена с неизвестным эффектом и лимиты. ContextPort сохраняет выбор ссылок, область операции, предел payload и завершение доступа с попыткой. |

В продуктовый tarball входят публичный API, адаптеры и документация. Пакет проверен из чистой копии без Git и `development/`. В установленном tarball выполнены импорт, декодирование конфигурации и явная загрузка локального плагина со skill и инструментом. Engineering policy harness отсутствует в runtime.

Промежуточный GitHub Actions на C09.7 обнаружил, что проверка импорта пакета не учитывала новые встроенные модули Node. C09.8 обновляет проверку и загружает Ajv при настройке инструмента. Публичный импорт остаётся доступен в распакованном tarball без установленных зависимостей.

Семантическая проба skill через Codex CLI 0.165.0 доставила адаптеру отдельные инструкции и пользовательское ограничение. CLI сообщил HTTP 401 и не вернул модельный результат до дедлайна. Соблюдение ограничения живой моделью остаётся UNVERIFIED. Нативный retrieval проверялся отдельно. [Результаты проб CLI и ACP](MCP_TRANSPORT.md)
