# Role Orchestrator

Role Orchestrator координирует работу одной или нескольких AI-моделей над задачей пользователя. Модель выбирает способ решения; Host обеспечивает передачу задач, доступный контекст, согласованные полномочия, ресурсы, отмену и восстановление исполнения.

**Состояние проекта: реализованы базовые контракты JavaScript и Controller с прямым ответом и модельным делегированием через внедряемые порты. Внешние адаптеры и пользовательские интерфейсы в разработке.** Описанные ниже возможности — целевые требования, а не заявление об их готовности.

Язык — **JavaScript (ESM), Node.js 24**. JSDoc и `checkJs` используются для проверки контрактов без транспиляции приложения. Репозиторий является **Nix flake**; базовая конфигурация предоставляет devShell и metadata checks. Устанавливаемые package/apps добавляются вместе с настоящим CLI, а не с заглушкой.

Рабочая среда может быть обычной директорией, Git-репозиторием, проектом с другой VCS или контекстом без файлов. Проверку наличия VCS и работу с ней выполняют модель и инструменты исполнителя. Нативный multi-agent режим провайдера не требуется.

## Использование после реализации

Планируемые поверхности: программный API, CLI и внешний ACP-интерфейс для Zed-совместимых клиентов. Поддержку конкретного исполнителя, модели и протокола следует считать подтверждённой только после проверки соответствующего адаптера. До появления исполняемой реализации здесь намеренно нет команд установки, заявленных как работающие.

Обязательные ограничения для работающих в репозитории агентов находятся в [AGENTS.md](AGENTS.md). Документация описывает самостоятельный новый продукт; знание какой-либо предыдущей реализации не требуется.
